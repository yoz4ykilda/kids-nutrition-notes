# 5岁男孩上吊，立刻处于濒死状态！太可怕了……

> 更新时间：2026-09-17 (UTC+8)

3日26日下午17时许，家住城东街道的5岁小男孩小辉，在家玩耍“上吊”游戏，竟被皮带嘞住喉咙窒息。事发后家人紧急送往医院进行抢救。

据小辉父亲周某介绍，事发时一家人正在吃饭，小辉独自在屋外玩耍。5岁的他不知怎么突发奇想，进行尝试模仿“上吊”的情节，不想假戏成真而险些酿成大祸。

皮带勒住脖子

5岁小男孩玩起“上吊”游戏

周某是安徽人，在东阳做点小生意。

在东阳这几年，他什么都干过，买卖水果，收购垃圾……为此，还购置了一辆电动三轮车。平常走街串巷用得着它，一天的生意做完了，晚上回来便停在租住的房子外面。

3月26日傍晚，周某与往常一样骑着三轮车回家，妻子烧好饭菜，一家人正坐着吃饭。

小辉这个时候正是贪玩好动的年龄，吃了几口饭便就溜了出去。周某已经习惯了这个儿子的把戏，并没有喝止。

不想悲剧就此发生了。

刚开始，小辉的嬉闹声还能传进屋子里。过了约摸十来分钟，听着小辉的动静小了，周某便打发8岁的大儿子去外面看看，以为小辉只是贪玩走远罢了。

“爸爸，快来啊！”不一时传来大儿子惊恐的叫声。

周某箭也似地冲了出去，看见儿子小辉瘦小的身体正挂在三轮车上。

周某说，孩子是将一根皮带系在三轮车的一根钢丝做的横杆上，然后……

周某已经记不清如何把孩子从皮带上解下来，他只记得当时小辉面色发黑，还尚有一丝鼻息，使劲拍背，可是怎么叫也叫不应。

为了节省时间，周某跟邻居借了一辆车，飞也似地将小辉送到了东阳市人民医院急救中心。

起死回生

父亲懊悔是他的一些小动作引起儿子模仿

送到急诊室时已经过去20分钟，小辉生命垂危。

医生检查发现，小辉颈部有一处约8cm长的勒痕，触目惊心。双侧瞳孔对光反应迟钝，无意识，已经处于濒死状态。

医护人员迅速准确的建立了静脉通道保证药物能够及时供给，实施气管插管辅助患者呼吸，开展心电监护时刻监测患者心跳、血氧浓度。

小辉窒息时间较长，抢救成功的难度非常大，面对此情形，现场医护人员凭借快速、准确的处置和坚持不懈的努力，经过积极抢救，最终从死神手里抢回了时间，救活了小辉。

急诊科副主任陈剑平回忆起小辉的抢救过程仍然记忆犹新，他说如果患者再晚几分钟被解救下来，就可能再也起不来了，大脑缺氧超过4-5分钟就造成不可逆性损伤，可能长期无法苏醒，呈植物状态，甚至脑死亡。

小辉在留观室观察了一天，第二天康复出院时，周某非常感激东阳市人民医院的急诊医生把自己的儿子从死亡边上救回来。言语间对自己的行为充满了懊悔。

周某说，他做生意用的这种电动三轮车，后车兜前部，也就是座位后面有一条钢丝做的横杆，平时他会把做生意用的秤子，或者其他一些小物件挂在这里。他怎么也想不到，自己平时无意识的动作，竟然成为儿子的模仿的对象。

尽管遇到的机会不大

但如果你发现有人正在吊死自己（自缢）时该怎么办？

1、大声呼救，并立即解除颈部勒索物。如自缢者仍悬吊着，应先抱住其身体后再剪断绳索，以防断绳后使之坠地摔伤；如自缢者站立吊颈，应先扶住其身体后再剪断绳索，否则会因其站立的身体突然倒下而摔伤。解脱后将其身体平放，以便实行抢救。

2、如自缢者呼吸与心跳已停止，应当立即行心肺复苏。同时寻求他人帮助拨打120。心肺复苏不要轻易停止，直至120人员到来。

3、如自缢者处于神志不清或昏迷状态，应迅速解开其农扣、腰带，将其放置于空气流通之处。平躺体位，不要轻易搬动和触及颈部，第一时间拨打120。

4、心肺复苏时如需打开呼吸道，只可轻轻地将其下巴向前提，而不要强行扭动其脖子或向后扳头。以免造成颈椎骨折、寰枕脱位等。

5、如自缢时间短、被及时解救者，临床表现为面色发绀、双眼上翻、舌轻度外吐、大小便失禁等，可在短暂休息后至正规医院检查有无颈椎损失等。
